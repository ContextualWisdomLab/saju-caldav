# 제품 요구사항 문서 (PRD)

## 제품 한 문장

사람이 이해할 수 있는 한글 역법 입력을 받아, 두 사람의 공통 관계 기준을 함께
참고할 현재 이후의 시간을 찾아 개인 CalDAV 캘린더로 관리하는 운영자 도구다.

## 대상과 문제

- 달력 기준·윤달·시각 미상 때문에 일반 사용자가 사주 입력 결과를 검증하기
  어렵다.
- 한자만 있는 결과나 미래 예언 문구는 신뢰와 접근성을 떨어뜨린다.
- 조건을 다시 계산할 때마다 수동으로 날짜를 찾고 캘린더에 옮기는 비용이 크다.
- 출생 정보와 동기화 일정의 삭제 범위가 분리되어 있으면 개인정보 신뢰가 무너진다.

## MVP 요구사항

1. 양력·한국 음력·윤달과 출생 도시/시간대를 입력한다.
2. 태어난 시각 미상도 저장하되 시주를 추정하지 않고 일주 기반 기능만 제공한다.
3. 출생 시각을 아는 경우 년주·월주·일주·시주를 한글 설명 우선으로 보여 주고,
   시각 미상 프로필은 시주를 비워 두며 한자는 보조로 제공한다.
4. 두 사람의 일지와 후보 날짜·시간 지지를 고정 관계표로 비교해 현재 이후
   공통 관계 후보를 관계 기준 점수·근거와 함께 보여 준다. 이 결과는 전통적인
   궁합·길일 판정이 아니다.
5. 사용자가 만든 허용 목록 규칙을 미리보고 CalDAV 컬렉션으로 동기화한다.
6. 프로필·캘린더·연결 원격 데이터의 삭제 범위를 확인하고 실제로 삭제한다.
7. 결과가 운세의 과학적 타당성이나 미래 사건 인과를 주장하지 않는다는 문구를
   모든 주요 흐름에서 유지한다.

## 비기능 요구사항

- Python 3.12 이상(운영 검증은 3.14 포함), 100% app statement·branch coverage
- 합성 데이터만 공개 테스트·CI에 사용, CalDAV 이벤트 최소 정보
- HTTP Basic과 Radicale owner-only, TLS/VPN 배치 가이드
- 규칙은 허용 목록, 입력·출력·오류는 한국어 초심자 우선
- 성별은 기록용으로만 보존하며 성별별 배우자성·대운 해석을 기본 후보에 섞지 않는다.
- Docker와 단독 FastAPI 실행을 모두 지원하고, 추후 MSA의 계산·발행 경계를
  독립 서비스로 분리할 수 있는 API 계약 유지

## 성공 지표와 금지 지표

성공은 첫 입력부터 이해 가능한 명식·후보·동기화 경로를 완주하고, 삭제 후
로컬/원격 잔존을 검증할 수 있는 것이다. 클릭 수나 추천률을 길흉의 정확도,
과학적 예측 성능, 의사결정 성공률로 해석하지 않는다.

## 범위 밖

대운·학파별 자시 관습 동시 제공, 의료·투자·법률 조언, 사용자 다중 계정·공개
마켓플레이스, 원격 자동 병합·무승인 배포는 별도 승인과 연구 없이는 구현하지 않는다.
